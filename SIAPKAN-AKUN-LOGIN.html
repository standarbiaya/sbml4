Pengaturan Akun Login SBML

Alat ini dapat dibuka langsung dari komputer Anda dan tidak mengirim username atau password ke internet. Gunakan hasilnya untuk membuat 3 isian di Cloudflare.

Offline · Password tidak disimpan ke file

Password acak 24 karakter lebih direkomendasikan. Catat password di pengelola kata sandi: nanti hanya nilai hash yang disimpan Cloudflare.

Salin ke Cloudflare → Worker sbml42 → Variables and Secrets → Production

Masukkan setiap Name dan Value. Jangan simpan hasil ini di GitHub atau membagikannya melalui chat.

Simpan password Anda. Jika lupa, buat hash baru di halaman ini dan ganti LOGIN_PASSWORD_HASH pada Cloudflare. Mengganti SESSION_SECRET mengakhiri seluruh sesi login.
